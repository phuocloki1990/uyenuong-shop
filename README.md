# Uyên Ương Shop

Website thử nghiệm bán bánh phu thê và mâm quả cưới tại TPHCM.

Bản đầu gồm:
- Trang chủ
- Trang chi tiết bánh phu thê
- Giỏ hàng chạy bằng localStorage
- Trang đặt hàng giao diện thử nghiệm

Bước sau:
- Đưa website lên Cloudflare Pages
- Kết nối Supabase để lưu đơn
- Gửi thông báo Telegram
- Trang quản lý trạng thái đơn hàng
